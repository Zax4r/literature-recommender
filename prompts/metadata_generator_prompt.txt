Твоя задача — сгенерировать карточки для КАЖДОЙ из этих книг в строго валидном JSON-формате.

Верни JSON-объект с ключом "books", который содержит массив объектов со следующей структурой:
{{
    "books": [
    {{
        "title": "Точное название книги",
        "author": "Имя и фамилия автора",
        "description": "Краткая аннотация сюжета и атмосферы (2-3 емких предложения)",
        "genres": ["Жанр 1", "Жанр 2"],
        "tropes": ["Троп 1", "Троп 2", "Троп 3", "Троп 4"]
    }}
    ]
}}

Правила:
1. Ответ должен быть ТОЛЬКО валидным JSON. Без текста до или после. Допускается обёртка в ```json ... ```.
2. Тропы должны отражать динамику, ключевые сюжетные механизмы и атмосферу.
3. ВСЕ текстовые поля — "description", элементы "genres" и "tropes" — пиши СТРОГО на русском языке.
4. Заполни карточки для КАЖДОЙ книги из списка, не пропуская ни одну. Число карточек в "books" должно быть ровно {num_chunks}.
5. "genres" — 2-4 устоявшихся жанра (именительный падеж), "tropes" — 3-5 тропов.
6. "author" бери из записи 'Автор - Название' без изменений; если авторов несколько, оставь всех через ';'.
7. Если книга малоизвестна, опиши её по названию, автору и жанру эпохи — без выдумывания деталей.
