# Интеллектуальная система подбора литературы

Курсовой проект. Пользователь описывает, что хочет почитать (**текстом, голосом через Whisper или файлом**), и получает
подборку похожих книг с объяснением и ссылками на магазины Беларуси. У пользователя есть профиль, личная библиотека
(прочитал / читаю / брошено / в планах, оценки, избранное), а теги книг (жанры и тропы) можно предлагать и оценивать
голосованием.

Репозиторий объединяет две части, работающие как один сервис:

| Часть | Что делает |
|---|---|
| **Бэкенд** (FastAPI + PostgreSQL) | Аккаунты (JWT), каталог, избранное, библиотека с оценками, теги с голосованием, история рекомендаций, сохраняемые сессии чата |
| **Фронтенд** (`frontend/`, React + Vite + TypeScript) | Отдельное приложение за nginx: вход и регистрация, лента, избранное, библиотека, теги, история рекомендаций и чат с сохранением сессий |
| **AI-чат** | Агенты (роутер → экстрактор → гибридный поиск в Qdrant → поиск магазинов → форматтер), локальное распознавание речи (faster-whisper), защита от prompt injection. Эндпоинт `POST /api/v1/chat` |

Связь между частями: у каждой книги есть `source_idx`, он хранится и в Qdrant, и в Postgres (`books.source_idx`).
Чат исключает из подборки книги, которые пользователь уже прочитал, читает или бросил, а его ответ сохраняется в
историю профиля.

## Быстрый старт

Нужны Docker и OpenRouter-ключ (бесплатного достаточно, см. ниже).

```bash
cp .env.example .env     # впишите OPENROUTER_API_KEY и свой SECRET_KEY
docker compose up --build
```

Что произойдёт:

1. Поднимутся Postgres и Qdrant.
2. Одноразовый сервис `init` применит миграции, загрузит каталог (6556 книг из `scripts/data`) в Postgres и Qdrant и
   создаст теги из жанров и троп. **Первый запуск занимает около 7 минут** (эмбеддинги на CPU и скачивание моделей),
   следующие быстрые: эмбеддинги кэшируются в `scripts/data/3_embeddings`, модели в томе `hf_cache`.
3. Когда `init` завершится, стартует `api`.

Дальше:

- Веб-интерфейс (контейнер `frontend`, nginx проксирует `/api` на бэкенд): http://localhost:3000/
- API без интерфейса: http://localhost:8000/
- Swagger: http://localhost:8000/docs
- Готовый админ из миграции: `admin` / `admin`.

> **Админ `admin` / `admin` нужен только для разработки.** Перед реальным запуском смените пароль и `SECRET_KEY`.

### Бесплатный профиль OpenRouter

Платный ключ не нужен. В `.env.example` задан профиль на бесплатной модели:

```
ROUTER_MODEL=nvidia/nemotron-3.5-super-vl:free
EXTRACTOR_MODEL=nvidia/nemotron-3.5-super-vl:free
FORMATTER_MODEL=nvidia/nemotron-3.5-super-vl:free
SHOP_SEARCH_ENABLED=false
```

- Бесплатный ключ создаётся на https://openrouter.ai/keys без пополнения баланса.
- `SHOP_SEARCH_ENABLED=false` отключает платный веб-поиск магазинов: в карточках будут ссылки на страницы поиска
  OZ.by, Ozon.by, Литрес и Лабиринт.
- Лимиты бесплатных моделей: 20 запросов в минуту и около 50 в сутки на аккаунт. Один запрос в чат делает 3 вызова
  модели, то есть примерно 15 запросов в чат в сутки. Один запрос занимает порядка минуты.
- Бесплатные модели нестабильны: проверенные нами Gemma `:free` отвечали 429 (общий лимит провайдера), а nemotron
  работал. Модель меняется переменными окружения без правки кода.
- Если `.env` не задан, чат не сможет отвечать (нет ключа), остальные функции работают.

### Фронтенд в разработке

Node на хосте не нужен: зависимости ставятся локально в `frontend/node_modules`.

```bash
cd frontend && npm install
npm run dev      # http://localhost:5173, /api проксируется на localhost:8000
npm run check    # проверка типов (tsc)
```

### Локальная разработка (без контейнера для API)

```bash
uv sync
docker compose up -d db qdrant
export DATABASE_URL=postgresql+psycopg://postgres:postgres@localhost:5432/literature
uv run alembic upgrade head
uv run python -m scripts.run_pipeline --skip-generate      # каталог в Postgres и Qdrant
uv run python -m app.cli sync-tags                          # теги из жанров и троп
uv run uvicorn app.main:app --reload
```

## Как устроен чат

```
вход (текст | аудио через Whisper | файл txt/pdf/docx/md)
  → Router (намерение + риск инъекции; видит историю диалога, продолжения сводит к теме поиска)
  → Extractor (жанры, тропы, место/время действия, исключения; видит историю диалога)
  → гибридный поиск (dense e5 + sparse BM25, RRF) в Qdrant, без книг из библиотеки пользователя
  → поиск магазинов (веб-поиск или ссылки-шаблоны)
  → Formatter (текст ответа + карточки; не повторяет запрос дословно)
```

Защита от prompt injection: пользовательский контент оборачивается как недоверенные данные
(`app/services/ai/guard.py`), промпты фиксированы в `prompts/`, агенты возвращают только валидный JSON, а агенты
магазинов и форматтер не видят сырой ввод пользователя.

Аккаунт и чат:

- Анонимам чат отвечает без исключения прочитанного и без истории.
- С заголовком `Authorization: Bearer <токен>` чат исключает книги со статусами `read`, `reading`, `dropped`, добавляет
  в каждую карточку `book_id` (id в каталоге) и сохраняет ответ в историю (`recommendation_id` в ответе).

## API

Префикс `/api/v1`. Защищённые методы ждут `Authorization: Bearer <токен>`.
Списки возвращают `{items, total, offset, limit}`, `limit` от 1 до 100 (по умолчанию 20).

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| POST | `/auth/register` | все | `{email, username, password}`, пароль от 8 символов |
| POST | `/auth/login` | все | форма: `username` (email или логин) и `password`, возвращает JWT |
| GET / PATCH | `/users/me` | токен | свой профиль (`display_name`, `bio`) |
| GET | `/users/{username}` | все | публичный профиль без email |
| GET | `/books?offset=&limit=` | все | лента каталога |
| GET | `/books/{id}` | все | карточка: автор, 250 символов описания, жанры, тропы, теги, `store_url` |
| PUT / DELETE | `/books/{id}/favorite` | токен | избранное (204, повтор безопасен) |
| GET | `/users/me/favorites` | токен | избранное с пагинацией |
| PUT / DELETE | `/books/{id}/entry` | токен | полка: `{"status": "read\|reading\|dropped\|planned", "rating": 1..5 или null}` |
| GET | `/users/me/library?status=` | токен | полка, фильтр по статусу необязателен |
| POST | `/books/{id}/tags` | токен | предложить тег `{"name"}`, он получает ваш голос «за» |
| PUT / DELETE | `/books/{id}/tags/{tag_id}/vote` | токен | голос `{"value": 1\|-1}` или его удаление, один голос на пользователя |
| POST | `/chat` | все | multipart: `message`, `file` (текст или аудио), `history`; с токеном исключает прочитанное и сохраняет историю |
| GET / POST | `/chat/sessions` | токен | сохранённые сессии чата: список и создание |
| GET / PATCH / DELETE | `/chat/sessions/{id}` | токен | история сессии, переименование, удаление |
| POST | `/chat/sessions/{id}/messages` | токен | multipart: `message`, `file`; ответ приходит потоком `text/event-stream` (`user`, `message`, `error`), книги попадают в историю рекомендаций |
| POST | `/chat/transcribe` | все | отладка: только распознавание речи |
| GET | `/recommendations`, `/recommendations/{id}` | токен | история чата: запрос, ответ, книги, ссылки магазинов |

С токеном лента и карточка содержат `is_favorite`, `status` и `rating` пользователя.
Теги возвращаются как `{id, name, score, my_vote}`; `score` это сумма голосов. Голосуют по `tag_id`, потому что имена
троп содержат запятые, слеши и скобки.

## Данные

- Каталог: 6556 книг в `scripts/data/2_generated_jsons/books.json` (карточки из `scripts/data/1_raw_lists/books.csv`,
  сгенерированные LLM: описание, жанры, тропы). Пайплайн: `python -m scripts.run_pipeline` (см. `--help`).
- Таблица `books`: `id`, `source_idx` (ключ, общий с Qdrant), `title`, `author`, `description`, `genres[]`, `tropes[]`.
- Теги (`python -m app.cli sync-tags`, выполняется в `init`): каждый жанр и троп книги становится тегом, около 20,5 тыс.
  тегов и 49,6 тыс. связей. Порядок из карточки сохраняется (вес по позиции), голоса поверх него. Команда идемпотентна.
- Связи: `favorites`, `user_books` (полка), `tags`, `book_tags`, `tag_votes` (первичный ключ
  `(user_id, book_id, tag_id)`), `recommendations`, `recommendation_items`.

## Настройки

Все переменные читаются классом `Settings` в `app/core/config.py` (из `.env` или окружения), у каждой есть значение по
умолчанию. Основные: `OPENROUTER_API_KEY`, `SECRET_KEY`, `ROUTER_MODEL`, `EXTRACTOR_MODEL`, `FORMATTER_MODEL`,
`SHOP_SEARCH_ENABLED`, `DATABASE_URL` (формат `postgresql+psycopg://...`), `QDRANT_HOST`, `QDRANT_PORT`,
`WHISPER_MODEL`, `STORE_SEARCH_URL`. В `compose.yaml` адреса БД и Qdrant для контейнеров задаются автоматически.

```bash
uv run ruff check . && uv run ruff format --check .
uv run mypy .
uv run pytest        # 21 тест на SQLite в памяти, сеть и ключ не нужны; LLM в тестах подменён
```

Новая миграция: `uv run alembic revision --autogenerate -m "описание"`; после неё `uv run alembic check` должен
сообщить об отсутствии расхождений. Линтер и mypy пока не проверяют код чата и пайплайна (`scripts`, `prompts`,

## Как проверено

- 21 автотест. Чат тестируется с подменённым оркестратором (интеграция с каталогом, историей и фильтром прочитанного).
- Миграции на PostgreSQL 17: одна голова, `upgrade`, `downgrade` и `alembic check` без расхождений.
- Полный стек `docker compose up --build` с нуля: загрузка 6556 книг в Postgres и Qdrant, 20,5 тыс. тегов, API.
- Сквозной сценарий по HTTP на этом стеке (36 проверок): аккаунты, каталог, голосование и свои теги, избранное,
  библиотека, живой запрос в чат через бесплатную модель (рекомендации приходят, прочитанные книги исключаются,
  история сохраняется), эндпоинт Whisper (после исправления версии `av` проверен отдельным запросом).
- Веб-интерфейс в браузере: вход, лента, карточка с голосованием за теги, чат с карточками и ссылками на магазины.

## Что пока не сделано и известные ограничения

- Голосовой ввод проверен только на эндпоинте распознавания (синтетический сигнал): запись с микрофона в интерфейсе
  и реальную речь мы не пробовали.
- Whisper при тишине или шуме может вернуть случайный текст (например, «you»).
- У каталога нет обложек: карточки текстовые. Авторы хранятся одной строкой (иногда через `;`).
- Модерации тегов нет: предложить можно любое допустимое имя.
- Нет refresh-токенов, смены пароля и ограничения частоты запросов на вход.
- Нет CI. Линтер и типизация для кода чата и пайплайна отключены.
- Качество подборки зависит от бесплатной модели: при её сбое (429) чат деградирует до простого ответа.
